## Table events

Table events are short interruptions that break up long play. They can win or lose you a little money and nudge the hidden scales or someone's standing, but they never open an act. This is a first pool for Mike to cut and add to; everything here is a proposal.

- **Fit the room:** each event is tagged to the venues where it fits, and its stakes scale with your current bet.
- **No repeats:** an event can't repeat for a few in-game days, and each one is at most a choice or two.
- **Seeds:** some events quietly set a seed that pays off much later.
- **Fair play:** regular play stays fair. A doubtful payout only happens in story moments, so no table event rigs a game.
