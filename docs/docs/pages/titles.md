## Dropped after checking

- *Hot Hand*: an existing slot game.
- *Cash or Crash*: an existing casino slot and app.
- *Let It Roll*: too close to the trademarked table game Let It Ride.
- *Gone Dark*: several small games use it or *Going Dark*.
- *Rocket 'n Roll*: an existing C64 game and a board game.
- *Ride the Rocket*: crowded by rocket "crash" gambling apps.
- *Odds On*: buried under betting sites.

## My picks

**Rags to Riverboats** is my favorite from this batch. It's the only one that says both "casino" and "climb from nothing" with no subtitle, and nothing else uses it. Close behind are **Win, Lose or Flare** and **Down to the Felt**. From earlier rounds, **Riding the Light** and **Even Money** are still strong.
