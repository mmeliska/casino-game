**Goal:** draft 10–15 sample events across the venue ladder.

Some seeds go nowhere. Authored drift changes NPCs on schedule, and the player's flags decide the flavor. Events use the JSON schema in the game design document.

Proposed rules for every seed:

- Nothing on screen says a seed was planted, and there's no journal; the payoff is a surprise (settled, Mike 2026-10-21).
- A reveal waits at least a week of in-game time, often an act, and fires only at a break point (settled, Mike 2026-10-21).
- The callback cue is a small inset of the seed's original panel plus one line, such as "The trucker from Bridgehead" (settled, Mike 2026-10-21).
- Missing a seed never locks a beat. The beat still happens, just without the bonus (settled, Mike 2026-10-21).
- The event schema gains a few fields: flags required, days since the flag, NPC standing, hidden-scale lean, season and act (accepted by Mike for now as a starting point, 2026-10-21; example below). Mike is building the game himself, so this is his starting format to refine when he codes the event director.

Proposed schema, using seed 3's payoff as the example (fin replaced by the spaceman, audit 1.6; updated 2026-10-30 to match the game design document). The seed itself only sets a flag (`helped_trucker`, with the day it was set).

```json
{
  "id": "trucker_saves_spaceman",
  "kind": "reveal",
  "venues": ["starflare_club"],
  "conditions": {
    "flags_all": ["helped_trucker"],
    "days_since_flag_min": { "helped_trucker": 7 },
    "act": 3,
    "beat": "last_night_on_the_floor",
    "npc_standing_min": {},
    "scales": {},
    "seasons": [],
    "heat_max": null
  },
  "fires_at": "break_point",
  "one_time": true,
  "callback": { "inset": "bridgehead_trucker", "line": "The trucker from Bridgehead." },
  "scene": "ink:seeds.trucker_saves_spaceman",
  "effects": { "flags_set": ["spaceman_saved"], "standing": { "gus": 5 } }
}
```

New compared with the game design document's draft: `kind: "reveal"`, `flags_all` / `flags_none`, `days_since_flag_min`, `act` and `beat`, `npc_standing_min`, `scales` (hidden-scale lean, e.g. `{"generous": 1}`), `seasons`, `heat_max`, `fires_at` and `callback`. Table events use the same shape with `kind: "table"` and a `rounds_between` range.
